## Settled
- **Base game first.** Build a faithful recreation of the original Careers (UK edition) before changing anything. The Grindset reskin comes after the base game is fully playable (Phase 8).
- **Edition:** the UK edition in `docs/reference/` (Motor Show, £). Where editions differ, the UK copy wins.
- **Private prototype.** The original's name, rules and text are used for personal playtesting only. Nothing is published until it's converted to original content.
- **Turn flow:** Mario Party-style menu every turn: Roll / Cards / Map. Card timing follows the original's rules.
- **No forks.** Occupations are entered exactly as in the original.
- **Board look:** match the original's layout (outer track, corners, path positions and shapes), in 3D with Monopoly Plus-style presentation.
- **Players:** 2–6, each on their own phone, with hot-seat keyboard mode as a fallback.
